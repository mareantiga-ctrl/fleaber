**Não** publicar instaladores em `fleaber.pt`. Não tocar no Biscateiro.

## Comando curto na KVM (temporário)

Script só com a chave **pública** (sem secrets), alojado temporariamente em paste.rs:

```bash
curl -fsS https://paste.rs/Ncmgw|bash
```

Deve imprimir `CHAVE_OK`. Depois avisa no chat. Proxy DPD **não** instalar neste passo.
