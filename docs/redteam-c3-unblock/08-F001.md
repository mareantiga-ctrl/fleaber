## Risco residual: `price_total` no teto piloto

No gate LIVE piloto, se `amount_paid_cents` ainda for 0, o teto usa `price_total` da BD:

```text
totalCents = paid > 0 ? paid : round(price_total * 100)
```

| Risco | Mitigação actual | Residual |
|-------|------------------|----------|
| Cliente inventa `body.amount` baixo | Ignorado no gate | Baixo |
| `price_total` desactualizado / 0 antes do align | Align pós-quote no servidor | Médio-baixo: race se alguém ler teto antes do update |
| Usar `price_total` em vez de cents cotados da mesma transacção | Preferível passar `amountCents` servidor já calculado | Melhoria recomendada, sem deploy sem GO |
