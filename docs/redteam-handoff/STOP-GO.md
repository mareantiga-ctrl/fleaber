# STOP / GO — cartão rápido para C3

## STOP (sem autorização escrita do dono)

- Dinheiro real Stripe / levantamentos / KYC pessoal  
- Expedição DPD produção  
- SMS pagos  
- Apagar ou alterar dados reais de clientes  
- Lives comerciais esquecidas activas  
- Modificar trabalho C2  
- Publicar secrets  
- Exploração ofensiva em produção na fase 0  

## GO implícito deste handoff

- Ler o repositório e esta pasta  
- Completar a matriz / exame numerado  
- Planear testes TEST  
- Pedir contas teste e GO para PoCs  

## Pedir GO explícito antes de

- Qualquer PoC que escreva na BD de staging/PROD  
- Activar Phone/SMS  
- Create DPD (mesmo QA)  
- Instalar APKs em devices do dono  
- Abrir directos longos

`OPS_STRIPE_LIVE_PILOT_MONEY_GO`, `OPS_STRIPE_LIVE_GO`, `OPS_DPD_COMMERCIAL_GO`, `DPD_LIVE_CREATE_ENABLED`, `OPS_SMS_SEND_ENABLED`
